One-time setup (about 5 minutes)
  1. Create a new Google Sheet. Click Extensions → Apps Script.
  2. Delete the sample code, paste the code below, and click the save icon.
  3. Click Deploy → New deployment. Click the gear and choose Web app.
  4. Set Execute as: Me and Who has access: Anyone, then click Deploy and approve the permissions.
  5. Copy the Web app URL (ends in /exec) into the box above.
function doPost(e) {
  var data = JSON.parse(e.postData.contents);
  var ss = SpreadsheetApp.getActiveSpreadsheet();
  data.sheets.forEach(function (s) {
    var sh = ss.getSheetByName(s.name) || ss.insertSheet(s.name);
    sh.clear();
    if (s.rows.length) sh.getRange(1, 1, s.rows.length, s.rows[0].length).setValues(s.rows);
  });
  return ContentService.createTextOutput('ok');
}

Everything runs in your browser. Your PDF is never uploaded, except the breakdown tables when you press Send, which go only to your own Google Sheet. Scene and character detection works on scripts exported from screenwriting software (not scans) and is pattern-based, so spot-check the results.
